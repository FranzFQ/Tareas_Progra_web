# hooks utilizados
## Usestate y useEffect
### - Se implemento el useState para guardar los datos tanto de la lista de las tareas asi como los datos de cada tarea individual para evitar la sobreescritura de los valores cada que se realiza una accion dentro de la pagina

### - Se implemento el useEffect para actualizar, guardar y cargar la lista con las tareas para evitar recargar la pagina y ver los cambios realizados de esta
